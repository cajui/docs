# Maintaining Cajuí ecosystem documentation

- Read README.md and docs/status.md before editing.
- Keep public content in English, independent of personal notebooks and installations.
- Document only evidence-backed behavior; label proposals, unmerged work and validation gaps.
- Keep source links pinned to reviewed public revisions; update the baseline intentionally.
- Technical contracts belong in their implementation repositories. Avoid duplicate specifications.
- Keep diagrams editable in Markdown using Mermaid and explain their scope in adjacent prose.
- Never add credentials, local paths, device-specific identities or private notebook material.
- Run python3 scripts/check_docs.py and inspect affected diagrams before publishing.
- Do not add a website build or enable Pages without a request to publish a site.
